# Fiche de Site

Application d'analyse de site pour architectes : position GPS, boussole, forme du terrain et rues, course du soleil, vent dominant (données Open-Meteo), relevé sur place, forces et faiblesses, fiche PDF.

Elle s'utilise dans le navigateur du téléphone et s'installe sur l'écran d'accueil. Les fiches restent enregistrées dans chaque téléphone.
